# 实验工作区

从已交接的方案开始。每次运行分配稳定编号（如 E1），每项验证用 V1 等编号。让一次失败也能留下配置、诊断和可接续的步骤。

| 位置 | 保存内容 |
| --- | --- |
| `src/` | 实际执行的 MATLAB / Python 入口、模型和处理、作图脚本 |
| `data/raw/` | 可分享的原始输入和来源；受限或大型输入记录固定版本、字节数、SHA-256、获取及验证方法 |
| `runs/<run-id>/` | 本次配置、输入版本、实际命令/软件版本、种子、容差、原始输出或失败诊断 |
| `results/` | 可从运行输出重建的整理数据、指标和图表 |
| `records/` | 六张 CSV：要求、来源、参数、主张、运行、验证。表内的文件路径相对研究仓库根目录，多个路径/ID 用分号分隔 |

发生有意义的进展即保存并提交，例如一个基线、一组工况或一次失败定位。登记设计提交号、实际执行代码版本和配置；记录假设/工况变更及受影响的结果。受影响结果重跑后再升级其状态。

交给写作者之前，把选定版本的代码/采集步骤、输入、主结果、绘图与验证材料连同解释冻结到 `report/`。保留运行 ID、原始位置和内容校验值，便于追溯。
