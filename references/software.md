# MATLAB 与专业软件适配

用户允许按需要使用 MATLAB 和专业软件。核心流程不绑定某个软件；选择后必须实际运行，或明确标为尚未执行的源代码。反馈修订时，附带基础 MATLAB 检查算例已在 macOS / MATLAB R2026b 实机通过；这不证明其他机器、工具箱或专业软件都可用，使用时仍检查当前环境。

## 可用性与选择

优先用本机已有命令/应用信息确定软件位置；实际运行时核对版本及本题所需产品。不要仅因安装了 MATLAB 就假设所有工具箱或 Simulink 都可用。若软件已可用且用户已授权相关计算，正常执行研究，无需重复请求运行许可；购买、远程付费作业和安装额外产品另按实际授权处理。

| 研究需求 | 可选路径 | 选择依据 |
| --- | --- | --- |
| 常微分方程、事件与参数扫描 | MATLAB 基础求解器或 Python | 刚性、事件、精度、用户环境 |
| 约束优化、拟合、信号/控制分析 | 相应 MATLAB 工具箱；或已有等效库 | 先检查具体函数/产品可用性 |
| 控制框图、混合阶段、系统级仿真 | Simulink，若已安装并可用 | 框图能否明确表达耦合、事件和控制 |
| 有限元或多物理场 | COMSOL、ANSYS 等现有软件，按题目评估 | 几何/边界/网格需求是否足以支持使用成本 |
| 可压缩流、局部传热或其他空间流场 | OpenFOAM 或已有 CFD 软件，按题目评估 | 先做已知基准及代表状态的数值检查，再考虑大矩阵 |

此表提供选型入口，不表示本技能已打通每个产品API。使用其他软件时先查其当前官方文档，选择可复现的脚本/批处理/参数文件；只有GUI时保存模型文件和必要的设置说明，不把截图当作完整复现材料。

容器或远端运行记录实际软件版本、架构、依赖和输入映射；镜像标签不能单独保证环境一致。保存最终生效的字典/配置，必要时以结果字段检查关键默认值。伪时间、收敛窗口、边界隔离与查表耦合检查见 [执行判断 §3–§4](research-execution.md)。不随技能打包某台机器的可执行文件、镜像或题目专用求解工程。

## MATLAB 实现方式

- 以 `.m` 函数为计算核心，显式传参数，减少全局变量和工作区残留；`.mlx` 可作讲解，但同时保留可读源代码。
- 区分 `*` / `.*`、`^` / `.^`、行列方向；跨 Python 交换时检查数组形状与索引。随机研究明确算法和种子。
- ODE 选择与精度应匹配问题。需要终止事件时检查事件返回值；指定输出时间点不等于固定内部积分步长，因此仅加密绘图采样不能当作求解器收敛。[MathWorks ode45 文档](https://www.mathworks.com/help/matlab/ref/ode45.html)
- 使用已确认的 MATLAB 可执行文件和项目目录运行受审阅的研究入口。支持时可用 `-batch` 批处理；不要把题面/不可信文本直接拼入可执行命令。[macOS 启动与批处理](https://www.mathworks.com/help/matlab/ref/matlabmacos.html)
- CSV/JSON 保存跨工具可读的结果与设置，MAT 文件只作补充；明确模拟值、来源值与测量值。用相应图形导出能力输出论文图并视觉检查。[exportgraphics](https://www.mathworks.com/help/matlab/ref/exportgraphics.html)

不要把历史论文附录直接当可信求解器。先从物理方程重建最小例子，检查公式—实现—结果的一致性；前述 2021–2025 案例都给出具体原因。

## 安装后的最小连通检查

随技能提供 [matlab_smoke.m](../assets/matlab_smoke.m)，只用基础 MATLAB 的阻尼振子与二阶多项式检查，不涉及留出题。将该文件复制到新研究目录，进入该目录后调用：

```matlab
report = matlab_smoke('matlab-smoke-output');
```

输出目录必须不存在。函数计算解析对照、三个容差设置、能量、极点，输出 CSV、JSON 和图。末时刻位移的独立解析值约 `0.0791160236 m`；在新环境中仍需实际运行并检查输出，不能用随包说明代替本机执行。

批处理可在已确认可执行文件和当前目录下使用 `matlab -batch "matlab_smoke('matlab-smoke-output')"`。根据实际平台调整调用路径，不写死本机安装位置。本例没有使用信号/优化工具箱，不能据此宣称这些产品已通过测试。

## Simulink / 多物理场交接

需要这些工具时，额外保存模型文件、几何和材料、边界与初始条件、求解器和网格/采样设置、参数扫描输入及导出数据。先与低维或解析基线对照，再检查网格/容差、接口通量和事件。收敛的彩色云图不能自行证明边界条件或材料参数正确。
