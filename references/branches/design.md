# 开放设计与决策路线

适用：需要选择方案、定义“有效/更好/真实”等指标，或物理结果还需转成行动决策。与机制路线共享建模和验证模块。

1. **定义评价对象。** 将模糊目标落到有依据的可测指标；若缺少公认阈值，报告多个合理定义下的结果，不掩盖价值/偏好假设。
2. **产生有物理差别的方案。** 比较因果机制或系统架构，避免把同一模型的几个参数值伪装成独立路线。写明可实施性、输入/输出和约束。
3. **先过滤不可行方案。** 检查材料、执行能力、能量/功率、时间及数据条件。抽象瞬时控制不自动等于可实施方案。
4. **为候选方案建立共同基线。** 同条件、同指标、同成本边界下比较。权重没有依据时展示权衡或 Pareto 结果，不用任意综合分数制造唯一最优。
5. **识别策略依赖。** 若涉及人的行为、主动控制或随机性，分开物理定律与行为假设；比较策略/先验变化时结论是否稳定。
6. **输出可使用的结论。** 说明适用条件、选择依据及后备方案。用户需要简易方案时，评估实际步骤、数据需求和误差，不能只交一个庞大的查表附件。

可迁移案例：2021 B 的损害定义；2022 B 的力学与决策假设；2025 A 的拾音器—滤波器—音色目标。金奖结论不是这些指标的唯一标准，见 [方法索引](../methods.md)。
