# 验证与修正

输入：题目要求、模型、代码、数据和拟写结论。输出：逐项检查、证据、通过/失败/未完成状态、可信范围与必要修正。

## 选择能推翻错误的检查

先写接受标准，再看模型输出。按实际机制选择，不机械执行所有项目。

| 风险 | 独立检查 | 失败后返回 |
| --- | --- | --- |
| 公式/代码不一致 | 小场景逐项代入、单位/方向、加速度是否除质量 | 模型/计算 |
| 能量或数量级异常 | 无驱动上界、通量收支、解析极限 | 模型 |
| 离散化伪影 | 时间步/网格加密、事件时间/峰值收敛、必要的第二方法 | 计算 |
| 参数/边界决定答案 | 可解释的情景与敏感性、边界附近检查 | 资料/模型 |
| 拟合掩盖误差 | 独立点、绝对/相对残差、最大误差、容许误差 | 模型/计算 |
| 结果证据不足 | 图是否来自实际输出、实测/模拟标签、来源适用条件 | 计算/资料 |
| 结论没有答题 | 每条要求对应结论和证据 | 审题/论文 |

解析推导与代码若共享同一错误假设，不构成独立物理验证。数值收敛证明离散求解趋稳，不证明模型适用于现实；高 R² 不保证误差满足任务容限；漂亮曲线不保证稳定或真实。

多方程耦合检查接口通量/单位、参考系及共同状态。带阶段切换的系统检查事件前后连续量、跳变量、耗散/做功。反馈系统检查最终发布系数而不只检查未舍入设计值。

## 工具

- 二阶离散滤波器：`python3 <skill>/scripts/numerical_checks.py biquad --a1 <a1> --a2 <a2>`，分母约定为 `1+a1*z^-1+a2*z^-2`；报告极点模与单位圆余量。稳定性不是频响/音色验证。
- 均匀加密序列：`python3 <skill>/scripts/numerical_checks.py convergence <csv>`，CSV 为 `h,value`、至少三行正步长。仅在等比加密且相邻差有意义时估计观测阶；不把往返振荡或舍入平台当作达到指定阶。
- 项目完整性：`python3 <skill>/scripts/audit_project.py <project>`。`integrity_ok` 检查格式、文件与引用，`status_findings` 单列未通过/未完成的登记状态；`ready` 和退出码仍执行原来的严格规则，不因文件齐全而忽略失败。详见 [项目约定](../../references/project-contract.md)。这些字段均不代替科学判断。

## 修正与交付

失败时保留可复现最小反例，再定位假设、实现或数据问题，修正后重跑受影响结果与图表。避免为迎合金奖结论调参。检查不适用时说明原因；无法完成的关键检查明确标注限制。

交给写作模块的每个主要定量结论应带条件、单位、有效位数、不确定性来源和实际证据。若研究只支持条件预测，论文就写条件预测；不能升格为经实验验证的普遍结论。

复杂数值项目按 [执行判断 §3–§5](../../references/research-execution.md) 分别报告迭代收敛、离散/边界依赖、闭合适用性和外部验证。说明失败尝试、后续修正及未解决限制；不要删除历史失败来获得绿色审计状态，也不要将审计不通过一概解释为文件丢失。

依据：[跨案例方法](../../references/methods.md)；2021–2025 案例中的作者结果均须区别于我们独立运行的验证。
