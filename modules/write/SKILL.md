# 从研究成果完成参赛论文

输入可以只有题面、研究笔记、代码、数据和图表，无需用户已有论文。输出应包括完整成篇正文和可编辑源文件；用户需要时完成导出及视觉检查。仅给提纲或建议不算完成写作请求。

首先读 [当届规则与 AI 披露](../../references/contest-rules.md)，从本轮起保留真实写作交互；已有 AI 使用一并核对记录覆盖。只有报告时先检查它是否足以独立支撑论文，缺口明确反馈，继续撰写有证据的部分。

## 1. 从证据搭建论证

只收到整体实验报告时，直接从包内 `README.md` 进入，按要求 ID、主张、证据和已核实来源建立论文结构。用同包材料独立还原方法、主表、图注、适用条件与局限。若一个核心数字或引用无法追溯，给出具体缺口并完成证据已支持的章节。见 [独立报告的写作交接](../../references/team-handoff.md)。

读取题目要求、已验证结果、假设与局限。建立“题目问题—主要结论—证据/图表—条件与局限”的对应。尚无支撑的结果标成待完成，不能凭写作需要补造。

选最能回答题目的主线，而非按工作日志逐日叙述。给每章一个明确职责：需要解释什么、用哪些模型/结果支持、与下一章如何衔接。可借用 [论证提纲模板](../../assets/paper-outline.md)，按题目合并或删减章节。

按 [论文竞争力](../../references/paper-quality.md) 提炼主导机制、基线对照和结论适用边界。摘要用最少篇幅呈现方法、关键假设、直接答案、主要数值与条件。贡献来自真实发现和解释，不靠声称创新或增加复杂度。

## 2. 完整撰写

先写可核实的方法和结果，再写讨论/结论，最后形成标题、摘要与引言。最终论文应覆盖实际需要的内容：问题与目标、假设/符号、模型与求解、仿真或实验方法、结果与验证、讨论/局限和直接回答题目的结论。

方法写到能复现关键结果：方程及适用条件、参数来源、初边值、算法与容差、数据处理、实际做过的验证。正文强调决定结果的步骤，长推导和实现细节放附录。

结果按研究问题组织，定量叙述与图表一致。讨论解释机制、与基线的差异和何时不适用。摘要只纳入实际获得且正文支持的主结果，不能引入新实验、性能数字或“首次”等无依据主张。

英文用清楚、克制、连贯的学术段落；如需中文说明，另作简短研究解释。不要把资料不足写成“已验证”，不要把模型输出写成真实测量，也不要把来源不明的参考文献补成看似完整的引文。

## 3. 图表、公式和引用

- 每幅主图对应一个论点；图注说明对象、条件、单位、数据类型和误差含义。凡称“仿真输出”的图，应实际从求解输出生成，而非仅画理论公式。
- 使用统一符号、单位、有效位数和编号。发布后的舍入系数仍需满足稳定性/容差；正文与附录、摘要与结论的数值一致。
- Markdown 源稿统一使用目标导出器支持的行内和独立公式定界符，检查反斜杠、上下标及单位命令是否处于数学环境；普通括号不能代替数学定界符。交付可编辑源稿前也做一次此项检查。
- 在使用外部事实/参数的位置引用已核实来源。来源尚未核实时保留明显草稿标记，不伪造 DOI、作者、页码或支持内容。获奖论文仅作为方法对照时，不冒充原始物理证据。
- 按当届要求在文末纳入真实 AI 使用报告，逐条核对工具、原始输入与完整输出；记录不足时标明具体缺口，不能补造。

## 4. 审校与交付

做三轮有明确目的的修订：①要求覆盖与证据/方程/代码一致性；②论证顺序、结果解释和局限；③语言、符号、版式和引用。按实际规则调整篇幅与模板，不预设往年页数就是要求。

完整稿再按 [独立审阅协议](../../references/paper-quality.md) 检查，问题登记到 [审阅记录](../../assets/review.md)，修正后验证受影响的数字与图表。审阅者看不到研究过程时仍应能理解方法和核查关键结果。无法安排独立审阅时明确说明实际自查范围。

默认可用 Markdown 组织正文，需要数学排版时用 [LaTeX 起始模板](../../assets/paper.tex) 生成可编辑稿，也可按用户需求输出 Word。模板不是完成论文，须用研究内容填充并删除草稿占位。LaTeX 可用宿主自带编译器或已存在的 TeX；Word 使用可用文档技能。不因某个工具缺失而丢弃已完成正文。

主要表格、摘要数字和结论数字尽量从同一份已接受数据生成；最终核对其条件与来源，避免手工抄写造成漂移。未知中心参数、指定敏感性幅度及模型间范围不能改写成最可能值、置信区间或已知误差上界。

导出后检查公式、图表、页边界、交叉引用、字体和参考文献。编译成功不等于视觉可读；先渲染整份稿件检查版面，再放大核对公式密集页和关键图表，按最终页面尺寸判断标签大小。无法导出时保留源文件并说明实际限制，不宣称已生成 PDF。

交付时说明论文状态：可审阅草稿 / 待补关键证据 / 已完成内容与版式检查。未核实当前提交规则或未解决证据缺口时，不标成“保证符合赛事要求”。

按 [提交核对表](../../assets/submission-checklist.md) 检查实际最终文件的首页、每页队号、匿名信息、摘要字数、AI 报告及文件命名，记录版本和 SHA-256。分别报告物理证据、版式、规则和披露状态；发送或上传按用户授权执行。

## 辅助写作技能

本模块已吸收 research-writing-skill 的“论证先于措辞”和 scientific-writing 的证据驱动章节组织。若已安装且当前工作需要，可以读取对应技能做进一步语言/引用/版式处理；按 [第三方适配](../../references/third-party.md) 保留 UPC 任务主线，避免套用临床报告、期刊投稿或其他赛事的专属要求。
