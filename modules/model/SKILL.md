# 假设、推导与模型

输入：题目要求、参数证据、候选路线。输出：方程、假设表、变量/单位、初边值和事件、基线与升级依据。

## 构造

1. 画系统边界与因果/能量/信号流，指定参考系和状态变量。逐段说明输入输出：例如位移→传感器电压→滤波→声压，每段的量和单位需闭合。
2. 用守恒、动力学、传热、波动或相应物理规律得到最简模型。先算数量级、无量纲组或解析极限，为代码设置独立参照。
3. 假设写成“简化什么—为什么可接受—何时失效—如何检查”。经验关系列适用域；对主结论敏感而无证据的假设转成情景或参数范围。
4. 给定初值/边值、符号方向、坐标原点、时间零点和终止事件。碰撞、接触/离面、阈值越过、阶段切换分别定义，避免在所有阶段使用同一个不适用的方程。
5. 耦合子模型通过共同状态和通量推进。若两个损失机制共同消耗同一储量，不能独立积分后直接叠加两条剩余量曲线；若并联物理机制被实现为串联，说明转换依据并比较传递函数。
6. 用增加机制前后的可观察差异决定复杂化。保留基线及其适用域，不把高阶模型视为天然更准确。

压力、温度、浓度等不同变量的近似分别论证；初始状态不自动构成持续边界。涉及多控制体或参数缩放时，按 [执行判断 §2](../../references/research-execution.md#2-把近似和耦合条件拆开检验) 检查通量是否重复计入，以及比较时固定的是有量纲条件还是无量纲相似条件。

用 SymPy 辅助推导时显式设置实数/正值等假设，避免过早浮点化；核对分支、奇异点和单位后再数值化。符号求解器给出表达式不等于物理分支选择正确。

## 比较与选型

比较的共同条件至少包括：要求/阈值、参数、初值、参考系、边界、误差度量。不能把不同定义下的答案平均为“更准确值”。区分参数不确定性、离散误差和模型结构差异。

若模型要求主动做功、瞬时碰撞或能量注入，显式计入能量与执行约束；无驱动状态先满足能量上界。最优值必须给允许的控制域和成本，不能由无限力或无限功率产生。

## 交接

给计算模块一份可实施模型，而不只是公式截图：状态向量、导数/代数约束、参数单位、初边值、事件处理、基准结果及预期数量级。给验证模块本模型最可能失效的 2–3 处及对应检查。
